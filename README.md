## About

This portfolio website features a terminal/code aesthetic with a green monochrome color scheme. It's designed to showcase web development projects and technical skills in a clean, professional manner with full responsive design support.

## Features

- **Responsive Design**: Fully responsive layout with mobile hamburger menu
- **Project Showcase**: Display projects with images, descriptions, and links
- **Skills Display**: Categorized skills with Font Awesome icons
- **Image Galleries**: Project detail pages with image galleries
- **Terminal Aesthetic**: Clean, code-inspired design with monospace fonts
- **Admin Panel**: Django admin interface for easy content management
- **Cloudinary Integration**: Cloud-based image hosting and management

## Technologies Used

### Backend
- **Django** - Python web framework
- **Python 3.12.x** - Programming language
- **PostgreSQL** - Database (development)

### Frontend
- **HTML5** - Markup
- **CSS3** - Styling with custom variables and flexbox/grid layouts
- **JavaScript** - Interactive features (hamburger menu, image gallery)
- **Font Awesome** - Icons

### Deployment & Hosting
- **Cloudinary** - Image hosting and management
- **Heroku/Platform** - Web hosting

### Development Tools
- **Git** - Version control
- **VS Code** - Code editor

## Showcase

### Skills

### Responsive Experience
The portfolio is fully responsive with:
- **Desktop**: Full sidebar navigation with project grid layout
- **Tablet**: Optimized two-column layouts
- **Mobile**: Hamburger menu navigation with single-column layouts

## Configuration

The portfolio uses environment variables for configuration:
- `SECRET_KEY` - Django secret key
- `CLOUDINARY_URL` - Image hosting credentials
- `DEBUG` - Development/production mode
- `DATABASE_URL` - Database connection string
